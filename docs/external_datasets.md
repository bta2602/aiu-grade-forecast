# Дополнительные данные о промежуточных и итоговых оценках

Команда `python scripts/import_external_grades.py` загружает две зафиксированные версии открытых таблиц, проверяет SHA-256 и создаёт `datasets/external/normalized.csv`. Всего в нём 1 277 записей по дисциплинам. Семь полей сохраняют источник, дисциплину, исходное обозначение семестра, два промежуточных балла, экзамен и итог. Пустое поле означает, что значение отсутствует. Исходные и преобразованные строки остаются локально.

| Источник | Р1 и Р2 | Экзамен | Итог | Ограничение |
|---|---|---|---|---|
| OpenIntro, университетский курс статистики, 233 записи за шесть семестров | Первый и второй экзамены | Третий экзамен курса | Опубликованный `course_grade` | Это отдельные работы. Университетские рейтинги Р1 и Р2 в AIU учитывают результаты за целый период. |
| UCI Student Performance, 395 записей по математике и 649 по португальскому языку | Оценки G1 и G2 за первый и второй периоды | Поле пустое | Годовая оценка G3 | Данные двух португальских средних школ. Продолжительность обучения и правила выставления годовой оценки отличаются от семестра AIU. |

В OpenIntro значения сохраняются с исходной точностью. В одной записи пропущен первый экзамен. После отбора по доступности первого рейтинга остаются 232 записи. Авторы обозначают `exam3` как третью работу. Использование её в качестве аналога экзамена AIU — допущение для эксперимента. У источника есть отдельный опубликованный итог курса. [Описание переменных](https://openintrostat.github.io/openintro/reference/exam_grades.html) · [Файл в репозитории авторов](https://github.com/OpenIntroStat/openintro/blob/f6372de1039e5075e87bd8e1e2ab194819a57894/data-raw/exam_grades/exam_grades.txt)

В UCI оценки G1, G2 и G3 принимают значения от 0 до 20. Импорт умножает исходный балл на 5 и сохраняет подлинные нулевые значения. Например, 14 переходит в 70. Шаг шкалы после преобразования остаётся равным 5 баллам. Некоторые ученики изучали оба предмета, поэтому 1 044 обозначает число наблюдений «ученик — предмет». Импорт использует только три столбца с оценками. [Paulo Cortez, Student Performance, UCI](https://doi.org/10.24432/C5TG7T)

Точные недели выставления промежуточных баллов в обеих таблицах неизвестны. Проверять, помогает ли добавление таких примеров в обучение, нужно на отдельных студентах из целевой казахстанской выборки. Сравнение на каждом источнике следует сопровождать указанием его собственной целевой оценки и шкалы.

Для возможного расширения StudyHub есть ещё казахстанское исследование по журналам успеваемости 20 868 студентов. Подготовленная авторами таблица содержит агрегаты одного студента за весь семестр и подходит для отдельной задачи прогноза среднего балла следующего семестра. Для прогноза по конкретной дисциплине в AIU нужны её собственные рейтинги и итог. [Публикация](https://doi.org/10.47852/bonviewAIA620210406) · [Таблицы и код авторов](https://github.com/MMR000/Smart_EDU_Score_Predict/tree/main/data_prepared)

## Атрибуция и распространение

Для независимой проверки переноса используется третий набор — курс векторного анализа Universidad Tecnológica de Bolívar в Колумбии, семестр 2024-I. В версии 2 автор опубликовал три учебные группы и 422 записи. Команда `python -m grade_forecast.utb` проверяет SHA-256 книги и создаёт `datasets/external/utb_2024_i.csv`. Оценки за периоды PI и PII и опубликованный итог переводятся из шкалы 0–5 в 0–100 умножением на 20. В колонке `third_period` сохраняется третий период, а в `prior_gpa_scaled` — опубликованный накопительный GPA на линейно пересчитанной шкале. Для проверки модели используются только PI и PII. Так исключается подмена прогноза информацией из третьего периода или приближённая трактовка накопительного GPA как простого среднего AIU. Точное соответствие сроков недельному календарю AIU не установлено. [Описание полей и книга версии 2](https://doi.org/10.5281/zenodo.22308083) · [Шкала оценок UTB, ст. 45](https://www.utb.edu.co/sites/web.unitecnologica.edu.co/files/descargas/resolucion_07_2019_reglamento_estudiantil_0.pdf)

На 273 записях есть числовой итог. Для остальных сохранён статус ухода с курса — у 91 студента после первого периода и у 58 после второго. Тест охватывает только студентов с известным итогом. Отчёт сравнивает модель с текущим рейтингом для первого периода и средним двух рейтингов для второго на тех же студентах. Из-за применения порогов AIU поздняя ошибка для отображаемых прогнозов охватывает 238 студентов. Отдельно сохранена ошибка формулы по всем 273 завершённым курсам. Источник UTB оставлен полностью вне обучения и выбора параметров. Автор исходных данных — Jeovanny de Jesus Muentes Acevedo. Лицензия версии 2 — CC BY 4.0.
